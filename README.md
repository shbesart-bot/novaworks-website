# NovaWorks website for GitHub Pages

This folder contains the latest NovaWorks website update with the animated spider mascot Nova, plus the legal pages and image assets. It is prepared for a repository-root GitHub Pages deployment. Relative links support the usual `https://ACCOUNT.github.io/REPOSITORY/` URL.

## Publish

1. Create a GitHub repository for the site and put these files at its root.
2. Push the `main` branch. The included workflow publishes the site automatically.
3. In the repository settings, make sure Pages uses **GitHub Actions** as its build and deployment source.

The production custom domain `novaworks-it.de` is not configured here. GitHub Pages needs a repository destination and domain/DNS setup before that domain can be switched over.
